# Frontend Tickets

Proyecto web para la gestion de tickets de soporte usando vite + typescript + react

## 📦 Requerimientos

- Git (>= v2.43.0)
- Node.js (>= v24.13.0)
- pnpm (>= 11.20.0)
- React (>= 19.2.8)

## 🔧 Instalacion

Clonar repository:

```bash
git clone https://github.com/sebasGZA/frontend_tickets.git
cd frontend_tickets
pnpm install
```

## ⚙️ Env variables

Creatr un archivo .env basado en las variables que se encuentran en el archivo .env.template

## ▶️ Correr Proyecto

```bash
pnpm run dev
```

## Arquitectura:
* Una estructura de carpetas simple basada en modulos de la aplicacion construidas, separado por componentes, intefaces, acciones y paginas
